# Authors & credits

**TriggerOS** — [Ttriggeredbot](https://github.com/Ttriggeredbot).

TriggerOS stands on the shoulders of these projects. Huge thanks to their authors:

| Project | What it gives TriggerOS |
|---|---|
| [switchroot](https://switchroot.org) | Android port for the Tegra X1 console: device trees, kernel, boot flow |
| [LineageOS](https://lineageos.org) | Android 15 base (LineageOS 22.2) |
| [hekate](https://github.com/CTCaer/hekate) by CTCaer | bootloader, SD/eMMC partition manager |
| [AOSP](https://source.android.com) | Android Open Source Project |
| [NVIDIA L4T](https://developer.nvidia.com/embedded/linux-tegra) | Linux for Tegra kernel and drivers |
| [Ubuntu](https://ubuntu.com) | the Linux userland inside TriggerOS |
| [Wayland](https://wayland.freedesktop.org) | protocol for our compositor `trigwm` |
| [foot](https://codeberg.org/dnkl/foot) | the terminal behind Tterminal |
| [Terminus Font](https://terminus-font.sourceforge.net) | the pixel font of Tterminal |
| [htop](https://htop.dev), [dialog](https://invisible-island.net/dialog/) | system monitor, installer UI |

TriggerOS is unofficial and not endorsed by any of the projects above.
